# TechCart. Curso FrontEnd y React

Repositorio del alumno. Construimos una tienda en línea, TechCart, clase por clase. Cada
carpeta `clase-XX/` contiene el código de esa clase, sus diapositivas en PDF y los
ejercicios para practicar.

## Cómo usar este repositorio

1. Entra a la carpeta de la clase, por ejemplo `clase-01/`.
2. Lee su `README.md`: qué vimos y cómo ver la página.
3. Abre el código y resuelve los ejercicios (están dentro del propio código).
4. Sube tus avances con `git add .`, `git commit` y `git push`.

## Ruta del curso (24 clases)

Construimos TechCart de a poco: primero HTML, luego CSS, luego JavaScript, luego TypeScript
y por último React.

- 01. La web y el HTML: semántica y formularios

**CSS**
- 02. Introducción a CSS: selectores, especificidad y box model
- 03. Flexbox
- 04. CSS Grid
- 05. Responsive: unidades, media queries, variables CSS, transiciones y modo oscuro
- 06. Tailwind CSS + componentes reutilizables

**JavaScript**
- 07. JavaScript: variables, arrays, map/filter/reduce
- 08. JavaScript moderno (ES6+): desestructuración, módulos, inmutabilidad
- 09. DOM + eventos + localStorage
- 10. Fetch + promesas + async/await
- 11. La tienda terminada: filtros, buscador, carrito con cantidades y checkout (MVP vanilla)

**TypeScript**
- 12. TypeScript aplicado a TechCart: tipos, interfaces y las tres aduanas

**React** (se dicta en TypeScript)
- 13. React + Vite + JSX
- 14. Componentes funcionales + props tipadas
- 15. Renderizado condicional + renderizado de listas
- 16. Manejo de eventos + useState
- 17. Estado derivado + buscador
- 18. useEffect + ciclo de vida
- 19. Consumo de API + estados de carga y error
- 20. React Router
- 21. Formularios controlados + validación por campo
- 22. Custom hooks + Context API + estado global
- 23. JWT + sesión + rutas protegidas + variables de entorno
- 24. Optimización + despliegue en Vercel + arranque del proyecto final

El proyecto final se presenta en semanas aparte, después de la clase 24.

Cada clase se publica aquí después de la sesión, con su código y sus ejercicios. A veces un
tema se continúa en la clase siguiente: si es así, empezamos con un repaso corto y seguimos.

## Herramientas

- Visual Studio Code (code.visualstudio.com).
- Un navegador: Chrome o Edge.
- Git y una cuenta de GitHub para subir tu trabajo.
- Extensión recomendada: Live Server.

Node.js y los frameworks se usan más adelante (desde la Semana 3 y en React). En las
primeras clases basta con abrir los archivos `.html` en el navegador.

Los datos e imágenes de demostración provienen de DummyJSON (dummyjson.com).
